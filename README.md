# 우리집 스윙 스크리너

매일 장 마감 후(평일 16:10) 자동으로 실행되어 결과를 웹페이지로 보여줍니다.

- `screener.py` : 계산 프로그램 (업종 RS → 주도주 → 눌림목 조건 → VPA 패턴)
- `docs/index.html` : 웹페이지
- `docs/data/` : 매일 자동으로 만들어지는 결과 (직접 고칠 필요 없음)
- `.github/workflows/daily.yml` : 자동 실행 설정

기본 조건은 `screener.py` 맨 위 '설정'에서 바꿀 수 있고,
웹페이지의 조건 입력칸에서 그때그때 바꿔 볼 수도 있습니다.
